# Estêvão Leite: sistema por dentro

O portfólio apresenta um desenvolvedor Full Stack para recrutadores de vagas plenas e seniores, remotas no Brasil. A identidade nasce da capacidade de trabalhar nas diferentes camadas de uma aplicação.

## Revisão antes de construir

O explorador de camadas é o elemento memorável. Não usar terminal falso, chuva de código, gradientes roxos, carrosséis automáticos ou animações em todas as seções. A visualização explica a atuação Full Stack; os projetos e resultados fornecem a evidência.

Os destaques seguem os repositórios atuais do GitHub. Capturas reais são identificadas; diagramas ilustrativos não fingem ser telas dos projetos. Resultados profissionais ficam separados dos projetos pessoais. Não inventar resultados, clientes, depoimentos ou tempos de resposta.
